# InTraGames
 
A small web app for playing traditional board games in the browser, including **Toguz Korgool**.
 
**Live:** https://kriscanin1-cloud.github.io/InTraGames/
 
## What you can do
- Play several traditional games
- Choose how to play: two players on one computer, online, or against a bot
## How it was built
- Built with **Claude** as my coding partner: first working version in about 4 hours, then iterated on it
- **React + Vite**, deployed on **GitHub Pages**
## Run locally
```bash
npm install
npm run dev
```
